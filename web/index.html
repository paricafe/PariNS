创建管理员账户

从安装提示的 setup-token 文件中复制初始化令牌。首次访问使用自签 HTTPS 证书，请先核对证书；公网访问请限制管理台的访问来源。

令牌仅用于首次设置，请妥善保管。
至少 12 个字符，建议使用专用的长密码。

设置 DNS 地址

先设置普通 UDP/TCP DNS。默认仅供本机使用，加密 DNS 和客户端限流可在管理台继续设置。

格式为 IP:端口，例如 127.0.0.1:5353 或 [::1]:5353。供其他设备使用时，请同时设置防火墙和客户端限流。

确认并启动

下方是即将保存的配置，可按需调整高级选项。启动前会检查配置、证书文件和端口。

返回修改地址后，此处配置会重新生成。启动后，可将设备的 DNS 指向本服务。

检查域名缓存

根据当前生效的设置查看缓存。检查仅在本地完成。ECS 填写发往上游的子网，留空表示未携带 ECS，/0 表示隐藏子网；其他选项请与查询一致。

输入域名，查看已有缓存和匹配规则。

粘贴证书与私钥

使用 PEM 格式，每项最多 64 KiB。导入会检查证书与私钥是否配对，保存并应用后生效。请另行确认有效期、域名和客户端信任。最多保存 32 份，相同证书会复用。

先在下方启用对应服务并填写地址。私钥仅保存于服务器私有文件；导入成功或退出登录后，输入框会自动清空。

按域名设置缓存

规则优先级：精确域名、较长后缀、指定记录类型，最后按列表顺序。每条规则可覆盖默认设置；总开关控制所有缓存。TTL 取上游有效期与配置上限中较短的时间。

管理台自身的 HTTPS 地址和证书，请通过启动参数 --web-listen、--web-cert、--web-key 设置，重启管理服务后生效。

parins.toml · 高级编辑
